# M3: подготовка безопасного privileged-испытания

Запрос владельца после независимого ревью PR #6, 2026-11-02.

Только read-only: проверить независимое от Android восстановление, исходный образ, точный откат
и причину framework-res APK v3 digest mismatch. Не перерабатывать M0–M3, не повторять успешные
сценарии. Не устанавливать candidate, не менять разделы/ключ/данные, не делать reboot/flash/merge.

Результат: [NO-GO с доказательствами и условиями](../docs/reports/M3-recovery-preflight.md).
У B нет bootable-состояния; независимый USB/recovery не подтверждён. Найден OEM image с тем же
build name, но прочитанные AVB-метаданные не совпадают с текущими. framework-res содержит старые
корректно подписанные метаданные при другом содержимом, включая изменённые manifest/resources.
Точное происхождение модификации UNKNOWN; системные файлы не изменялись.

Следующий шаг — отдельно согласованная физическая проверка независимого recovery без записи,
с подтверждённым host/loader и возвратом Android/ADB. До этого priv-app испытание запрещено.
