# Приёмка

Статусы: **PASS**, **FAIL**, **NOT_RUN**. Для каждого аппаратного пункта записать
устройство/ОС, commit, настройки потока, действия, наблюдение и очищенное свидетельство.
Этот файл — план тестов, не результат выполненных проверок.

## M0

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| M0-01 | Сборка из чистого checkout | Рабочий Gradle Wrapper, APK, записанные версии и команда |
| M0-02 | Обычная и короткая YouTube-ссылки | Корректный videoId; посторонние hostname и адреса отклонены |
| M0-03 | Три публичных VOD на H728 | Каждый реально воспроизводится со звуком; качество записано |
| M0-04 | Раздельные video/audio, если доступны | Синхронный звук, не немое видео; иначе NOT_RUN с причиной |
| M0-05 | Три элемента очереди | Переход по событию окончания, строго в заданном порядке |
| M0-06 | Конец последнего | Наш экран ожидания, нет рекомендаций/нового ролика |
| M0-07 | STOP/NEXT во время получения потока | Запоздавший ответ не возобновляет старое видео |
| M0-08 | Ошибочный/недоступный ролик | Управляемая ошибка, ни браузера, ни внешнего приложения |
| M0-09 | Потеря/возврат сети | Нет busy loop/краша; очередь сохранена; STOP остаётся в силе |
| M0-10 | Перезапуск процесса | Сохранились ID, порядок, позиция и play/pause/stop intent |
| M0-11 | Child playback surface | Нет нашего управления и интерфейса YouTube поверх видео |
| M0-12 | Регрессии среды | Штатный Launcher, другие APK и сетевые настройки не изменены |

Для M0-05 нужен хотя бы один настоящий естественный конец короткого тестового видео;
перемотка к финалу может ускорять остальные проверки, но не заменяет все события окончания.
Минимальный сеанс на стенде — 20 минут суммарно, не считая одной лишь загрузки APK.
Unit-тесты покрывают порядок/stop/restart/stale response/error и нормализацию ссылок.
Сетевые живые тесты отделены от детерминированных unit-тестов.
Если H728 недоступна, код и сборку можно закончить, но аппаратную приёмку пометить NOT_RUN.

## M1

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| M1-01 | Android-браузер и Ubuntu-браузер | Оба управляют одной приставкой |
| M1-02 | Неавторизованный клиент / отозванный токен | Нет чтения приватной очереди и управляющих действий |

## M2

Плейлист больше одной страницы; неверная ссылка; скрытые/удалённые элементы;
лимит импорта; отмена до применения; сохранение порядка; импорт выбранных пунктов.
Добавленный автором позднее ролик не появляется в сохранённой программе.
Ошибка пагинации не скрывается за словом «полностью импортировано».

## M3

Проверить штатный Launcher и родительский возврат до и после ограниченного режима.
Home/Back/Recents/специальные кнопки/voice/CEC и применимые устройства ввода.
Три reboot: очередь шла, была на паузе, была остановлена. Очередь и намерение восстановлены.
Не путать lock task с screen pinning. Не скрывать ограничения OEM-прошивки.

## M4

Управление с другой сети; отсутствие публично открытой панели; недоступность домашнего
SSH-узла (если выбран); отключение приставки; честные статусы и отсутствие позднего сюрприз-запуска.
Непрерывное воспроизведение выбранной очереди минимум два часа и возврат после обрыва сети.
