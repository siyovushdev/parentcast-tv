В существующий Android-модуль добавлены:

- Анонимное получение публичных статических PL/OLAK5uy плейлистов существующим yt-dlp
  `2026.10.26`: flat metadata, без скачивания видео и обхода ограничений. Версии yt-dlp,
  Media3 и зависимости не менялись. Существующая debug-сессия применяется плеером как раньше.
- Получение страниц до контрольного 501-го элемента, исходные индексы/порядок и известный count.
  Более 500 — явный LIMIT_EXCEEDED, применение и сохранение запрещены.
- Фоновый предпросмотр в собственном IO scope с отменой процесса, timeout 120 секунд,
  TTL 15 минут, ограничениями памяти и изоляцией по сопряжённому устройству.
- COMPLETE/PARTIAL/ERROR/CANCELLED, известные названия/длительности/канал; private/deleted,
  live/upcoming и UNKNOWN различаются. UNKNOWN никогда не называется подтверждённо доступным.
  Завершённый перечисленный VOD с ID/названием/длительностью допускается к осознанному выбору
  с явной подписью «доступность не проверена». Проигрывание всё равно может быть запрещено YouTube.
- Checkbox, выбрать все/снять, отмена, отдельное явное применение. Получение, выбор и сохранение
  подборки не изменяют очередь. PARTIAL с подтверждённой публичностью позволяет выбрать только
  полученную часть; без подтверждения публичности выбор запрещён.
- Atomic batch в PlaybackCoordinator: проверка queueVersion и одна запись полного состояния
  вместе с receipt команды, затем публикация состояния. Нет вызовов player.play/stop/prepare.
  Повтор проверяется до версии и даже при исчезнувшем preview после restart. Окно 24 часа,
  максимум 1000 действующих batch receipts; при исчерпании новые команды отклоняются явно.
- Приватный атомарный файл `noBackupFilesDir/saved-collections.json`: только фиксированные
  упорядоченные videoId, имя и служебные данные создания. Нет source URL, обновления/подписки.
  Просмотр, повторное добавление и удаление. Лимиты: 50 подборок, 10000 ID суммарно, 500 на подборку.
- Существующие токены/PIN/Host/Origin/CSRF и очередь M1; канонический URL из проверенного ID,
  безопасный textContent для недоверенных строк, явные конфликты/причины, UTF-8 JSON и лимит body 64 KiB.

Независимые пакеты, UI и тесты выполнялись субагентами; интеграция, ревью и аппаратная приёмка — root.
M3/M4, HOME/Launcher/Device Owner, Happ, FamilyTV и системные настройки не изменялись.

## 4. Ограничения и исправленные проблемы

- **REGRESSION, исправлено:** UI отправлял header m2 вместо разрешённого m1, получал403.
  Существующий протокол восстановлен; добавлены contract и настоящий HTTP integration tests.
- **IN SCOPE, исправлено:** отсутствие необязательного ffmpeg ошибочно делало flat metadata PARTIAL.
  Игнорируется только конкретное предупреждение о missing libffmpeg.so; реальные warning/page errors
  по-прежнему PARTIAL. Компонент не устанавливался, зависимости не менялись.
- **IN SCOPE, исправлено:** NanoHTTPD без charset декодировал JSON как ASCII и портил русское имя.
  JSON нормализован в UTF-8; точный roundtrip проверен настоящим HTTP и Chrome→H728.
- **UNKNOWN:** при воспроизведении наблюдались периоды BUFFERING; затем показаны реальные кадры
  и рост позиции. Причина сетевых пауз не устанавливалась; непрерывный просмотр без буферизации
  не обещается и не подменяется статусом PLAYING. Субъективное прослушивание HDMI-звука — NOT_RUN;
  AAC-дорожка реально выбрана Media3. Изменений extractor/Media3 ради этого не делали.
- **OUT OF SCOPE:** private/unlisted/Mix/live, подписки/рекомендации, downloads, M3/M4. HTTP внутри
  доверенной LAN не шифруется; приложение не объявляется защищённым детским режимом.
- Настоящий сетевой отказ страницы и добавление ролика внешним автором — NOT_RUN; синтетические
  тесты названы отдельно. Нерешённых FAIL в реализованном M2 нет.

Финал H728: 24 элемента (исходные20 + импорт2 + явное повторное добавление подборки2),
currentIndex21, version69, position71849мс, STOPPED/STOP. Один фиксированный список из двух ID сохранён.
Тестовые YouTube cookies присутствуют и сессия включена; их значения агент не читал и не удалял.
Временный API-токен испытаний отозван; Chrome оставлен сопряжённым. Локальный PIN вне Git, права600.
Merge и Release не выполнялись.

Дополнение после независимого ревью, 2 ноября 2026: **IN SCOPE, исправлено** —
элемент с явным `availability="unlisted"` теперь имеет UNSUPPORTED и selectable=false.
Логика UNKNOWN при отсутствующем availability сохранена. Целевой тест публичного плейлиста
с unlisted/UNKNOWN/public воспроизвёл ошибку до исправления и прошёл после него.

не затрагивались. APK выше относится к исходной аппаратной приёмке до этого исправления;
