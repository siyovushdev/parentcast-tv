# M1 — родительский LAN-веб-пульт

## Результат

Один Android APK с нативным плеером и встроенным HTTP-сервером. Родитель управляет H728
через адаптивную русскую панель в Android-браузере и Ubuntu-браузере по домашнему Wi-Fi.
Приставка остаётся единственным источником очереди и состояния Media3.

## Обязательная реализация

- Локальные HTML/CSS/JavaScript внутри APK, адрес панели на TV debug-экране.
- Добавление одной/нескольких ссылок, очередь и реальные статусы, play/pause/next/stop,
  play-now, удаление и изменение порядка ожидающих, очистка только ожидающих.
- Первичная установка PIN на TV, PBKDF2-хеш, ограниченное по времени одноразовое сопряжение,
  отдельные токены устройств и отзыв. Токены только в Authorization header, не в URL/логах.
- Ограничение попыток PIN, Host/Origin/custom-header проверки, запрет CORS/CSRF/DNS rebinding.
- Идемпотентные команды, версии очереди и явный конфликт вместо молчаливой перезаписи.
- Исключить PIN, токены и cookies из Android backup, не очищая существующие данные.
- Unit/integration тесты, debug APK, lint, Draft PR и аппаратная приёмка M1-01…M1-07.

## Границы

Только доверенная LAN, HTTP без шифрования. Никакого HTTPS/Internet/облака/M2–M4, HOME,
Device Owner, Lock Task или изменений Happ/FamilyTV. Тестовые YouTube cookies не читать
и не удалять. Merge и Release не выполнять.

## Приёмка

Проверить реальное управление и воспроизведение на H728 через Ubuntu и доступный Android-телефон.
Если телефона нет, соответствующие проверки отметить NOT_RUN, не подменять их эмулятором.
