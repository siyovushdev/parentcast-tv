# Загрузка большого плейлиста и порядок серий — 2026-11-05

IN SCOPE: проверить остановку подготовки VK «Истории Пророков» и неправильный для
просмотра порядок. Разрешена остановка приложения для обычного debug update без очистки.
Ветка `codex/playlist-storage-order` от `25a745a` (PR #15 с объединённым #16), без Merge.

Диагностика реальной H728: план61, READY20, ERROR1/NO_SPACE, WAITING40, paused=true.
Использовано10,704,993,730 из10,737,418,240bytes; остаток32,424,510bytes. Android свободно
4,734,377,984bytes, но лимит библиотеки10GiB намеренно меньше. Зависание сети не подтверждено.
Список начинается с#58;#25,#11,#31/#32 дополнительно находятся вне порядка номеров.

- Показать причину остановки в состоянии и загрузках; различать лимит библиотеки и резерв
  Android, не округлять малый доступный объём до0GiB. Не обещать, что весь список поместится.
- Явная подготовка повторяет ошибки только выбранного плейлиста и сохраняет готовые/partial.
- Сортировка черновика по явному номеру серии/урока; неизвестные номера — в конце,
  одинаковые номера и дополнительные видео сохраняют относительный порядок.
  Сохранение через существующую versioned/idempotent команду без изменения playback.
- Выставить этому плейлисту порядок серий1…58; другие плейлисты и общую очередь сохранять.
- Готовые файлы не удалять без ответа владельца на конкретное предложение. Не поднимать
  лимит самовольно, не включать автоудаление и не менять исходный порядок новых импортов.
