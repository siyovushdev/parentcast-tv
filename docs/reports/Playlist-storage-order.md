## Исправление на ПК

- Автоматическое удаление при заполнении бюджета убрано целиком, включая файлы, оставленные
  после удаления видео из программы. NO_SPACE останавливает подготовку и сохраняет файлы.
- Ручной CLEANUP учитывает всю очередь, включая другие плейлисты; без известного актуального
  снимка очереди отказывает. Свои локальные видео по-прежнему защищены.
- `files.inQueue` относится ко всей программе, а не только выбранному плану.
- Причина остановки видна также в верхнем состоянии веб-пульта; отдельно лимит/резерв
  Android, маленький остаток показан вMiB. Готовые ролики доступны для просмотра.
- Явная подготовка повторяет ошибки выбранного списка, сохраняя READY и partial других.
- Черновик сортировки по #/№/серия/урок/выпуск, численно1→2→10; без номера — в конце,
  относительный порядок равных/дополнительных сохраняется. Сохранение прежней защищённой
  командой group-order с queueVersion/receipt, без команды PLAY и без изменения позиции.
- Форматы очереди/подборок, Media3, pinned yt-dlp, источники/авторизация и лимит не менялись.
