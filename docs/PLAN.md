# План реализации

## M0 — основа плеера, завершённый этап

Новый приватный репозиторий и Android-проект. Нативный плеер + NewPipe Extractor +
минимальная очередь + восстановление сохранённых данных. Отладочный ввод ссылок.
APK, локальные тесты, реальные проверки на доступной H728, Draft PR.
Не делать HOME, сервер, веб-пульт или удалённый доступ на этом этапе.

## M1 — родительский веб-пульт по домашней сети, реализован (ограничения в отчёте)

Встроенные API и веб-панель, сопряжение и PIN, управление очередью,
состояние настоящего плеера. Проверить одновременно с Android и Ubuntu;
после закрытия обоих браузеров просмотр продолжается.
Это уже полезный просмотр под наблюдением родителя, но не гарантированно закрытая приставка.

## M2 — плейлисты и сохранённые программы, реализован

Предпросмотр, пагинация, частичные ошибки, выбор роликов, фиксированный импорт.
Новые видео автора не проникают в очередь автоматически.
Реализация и аппаратные результаты: `docs/reports/M2.md`; сетевой fault injection и изменение
внешнего плейлиста автором отмечены отдельно от unit-тестов. M3 запущен отдельным заданием; M4 не начат.

## M3 — HOME BETA, завершён в согласованном объёме

Настройка/возврат Launcher, родительский вход, проверка Lock Task на H728,
поведение после reboot, восстановление STOP/PAUSE/PLAY, проверка путей выхода.
Обязателен безопасный выход до закрепления приложения.
Обычный HOME/PIN проверен, полноценный kiosk пока не принят: системные SETTINGS/ASSIST обходят
обычный режим. Подготовлен отдельный privileged ALWAYS-кандидат без назначения DO.
Read-only совместимость и условия установки/отката: `M3-privileged-plan.md`;
результаты, включая NOT_RUN reboot/privileged, — `reports/M3.md`. Системная установка не разрешена.
M0–M3 объединены в main по отдельному разрешению владельца; финальная обычная сборка и короткая
приёмка — `reports/v0.1-home-beta.md`. Полноценный kiosk не заявляется, privileged остаётся NO-GO.

## M4 — управление из другой сети, отложен

Та же панель через согласованный SSH-туннель или частный VPN.
Не создавать облачный сервер. Проверить статус offline, доставку и фактическое исполнение.
Затем непрерывный сеанс выбранной очереди не менее двух часов и проверка восстановления сети.

## Организация

Один этап — одна ветка / Draft PR. Сначала текущая задача, затем проверка результата.
После M3 агент останавливается: следующие этапы запускаются новым заданием.
Финализация v0.1 HOME BETA завершает текущий проект; M4 и privileged-испытания не начинать.
Не устанавливать произвольное целевое количество тестов и не строить изоляцию/оркестратор.

## После HOME BETA — подготовленная программа, реализована; Draft PR

Отдельно разрешена 2026-11-03: `tasks/Prepared-programme.md`. Полная подготовка
выбранных родителем роликов, затем локальный просмотр и фоновая подготовка следующих.
Реализация и границы проверки — `reports/Prepared-programme.md`.
Существующая HOME BETA остаётся базой; M4 и privileged по-прежнему отложены.
