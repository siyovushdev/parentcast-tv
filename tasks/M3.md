# M3 — HOME, автозапуск и родительский режим

База: `m2/playlist-import`, `940564113dc1c68184211cdfc1e73d43c6dc7d99`.
Ветка: `m3/home-kiosk`; Draft PR в M2. Merge/Release не выполнять.

## Результат и границы

- Поддержка Android HOME штатным выбором, системный запуск выбранного HOME после boot,
  без boot receiver, фонового старта Activity и циклов перезапуска.
- Тот же PIN M1 для локального входа: удержание MENU/DPAD Center открывает только форму;
  ограничение попыток сохраняется, родительская сессия истекает и закрывается при уходе приложения.
- Включаемый родителем просмотр, отдельные фактические HOME/immersive/pinning/Lock Task статусы.
  Настоящий Lock Task при DPC-разрешении либо в отдельно собранном privileged-кандидате ALWAYS;
  не выдавать HOME+PIN за системную блокировку.
- Сначала сохранить штатный Launcher и проверить возврат, затем HOME/ограничения.
  Родитель может отключить режим и собственный HOME alias, вернуть Launcher через PIN.
- Настройка автопродолжения: выключена по умолчанию. PLAY восстанавливает выбранный ID/позицию
  и играет только при включённой настройке; PAUSE/STOP не переходят в PLAY.
- Сохранить M0–M2, очередь/подборки/пульт, cookies/PIN и остальные данные.

## Приёмка

Сборка, JVM/integration и lint; update debug APK на подтверждённой H728 без очистки данных.
Штатный HOME picker и фактический resolver/возврат, PIN/обычные кнопки/системные выходы,
родительский пульт и сохранённые данные. Каждому аппаратному сценарию PASS/FAIL/NOT_RUN.
Независимые задачи разрешены субагентам; главный агент интегрирует и проверяет.

## Безопасность H728

Device Owner на стенде отсутствует. Новый DO, factory reset, root/прошивка, изменение других APK,
Happ/FamilyTV, отключение ADB и системные обходы запрещены. Существующий PIN не сбрасывать;
локальный `.dev/m2/current-test-pin` разрешён без вывода. Только обратимые HOME-тесты после recovery.

Уточнение владельца: подтверждённого возврата ADB после reboot нет; проверяются только read-only
параметры. Если возврат не подтверждён, все три настоящих reboot — NOT_RUN, без остановки остальной M3.
M4 не начинать. После M3 остановиться.

## Дополнение владельца: privileged ALWAYS

Исследовать Android 14 и H728 read-only, сравнить только публичные сертификаты, подготовить
отдельную private Activity `lockTaskMode=always`, проверять фактический LOCKED, PIN-выход и план отката.
Не устанавливать candidate в системный раздел, не менять signer установленного APK и не делать reboot.
Platform-ключ не читать/экспортировать/публиковать. Для ALWAYS требуется privileged flag, platform signer
не является самостоятельным условием. Первый сеанс не сохраняет автоматическое включение на boot.

Результаты: [аппаратный отчёт](../docs/reports/M3.md),
[совместимость и условный план](../docs/M3-privileged-plan.md). Проверяемые части реализованы;
реальный privileged LOCKED и три reboot остаются NOT_RUN до согласованного безопасного восстановления.
