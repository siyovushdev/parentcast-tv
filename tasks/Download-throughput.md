# Медленная подготовка на H728 — 2026-11-07

IN SCOPE. Владелец попросил проверить медленную загрузку при тарифе до500Мбит/с;
приставка свободна, диагностика разрешена. Не менять Wi-Fi/VPN/Happ/систему,
сохранить программу, partial-файлы, готовые видео и доступы. Без Merge/reboot.

Измерить отдельно фактическую подготовку, Wi-Fi, LAN и получение текущего VK
на H728 без записи. Не выдавать скорость тарифа/link rate за throughput источника.
Небольшая проверка microSD из отдельного UID-процесса не получила доступ;
её результат — NOT_RUN, не замена измерению внутри приложения.

Кодовая причина: один InputStream.read с buffer128KiB не гарантирует заполнение
буфера. Результатом часто служит маленький сетевой пакет, а каждый пакет вызывает
дорогой fresh Android storage snapshot/canonical/stat/quota gate. Собрать128KiB
перед физической записью, сохранив live volume/quota/free-reserve проверку каждой
записи, отмену между чтениями, partial при сетевой ошибке и исходный Range retry.
Не добавлять параллельные соединения и не менять политики источников/качество.

Проверки: short reads/exact bytes, network error tail, cancellation, quota/storage
failure без повторной записи; существующие Range/validator tests. Unit/lint/debug/
release compile. Затем обычный debug update без очистки на serial…84201a,
восстановить прежнюю подготовку/STOP и измерить реальный прирост скачанных байтов.
