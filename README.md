# ParentCast TV v0.1 — HOME BETA

Домашняя тестовая версия для использования под наблюдением родителя. Не является развитием или копией FamilyTV.

**Назначение:** родители выбирают YouTube-видео с Android-телефона или Ubuntu,
а Android-приставка воспроизводит только составленную ими программу.

## Статус

Проверенная цепочка M0–M3 (PR #1–#6) объединена в `main`: плеер, родительский LAN-веб-пульт,
импорт публичных статических плейлистов, фиксированные подборки, HOME и локальный PIN-выход.
M4 отложен. Privileged Lock Task на H728 остаётся **NO-GO** до подтверждённого восстановления прошивки;
обычная сборка не содержит экспериментальную ALWAYS Activity.
Плеер использует Kotlin, Media3 и yt-dlp `2026.10.26` на встроенных
Python 3.12/QuickJS. Есть атомарная очередь, вход браузеров по действующему родительскому PIN,
отдельные отзываемые токены и русская адаптивная панель. NewPipe сохранён для сравнения.
Приватный репозиторий: `siyovushdev/parentcast-tv`. Это HOME BETA, не production-ready и не полностью
защищённый kiosk. Итоговая приёмка и APK: [docs/reports/v0.1-home-beta.md](docs/reports/v0.1-home-beta.md).

## Состав решения

- Один Android APK на приставке: нативный плеер, очередь, локальное хранение,
  HTTP-сервер и встроенная родительская веб-панель.
- Телефон и Ubuntu используют одну адаптивную веб-панель по домашней сети.
- Приставка получает видеопоток сама. Постоянно работающий Ubuntu для локального просмотра не нужен.
- Удалённое управление через защищённый канал — отдельный этап, не M1.

## Сборка M0–M3

Нужны JDK 17 и Android SDK с platform 35. Все версии Gradle и библиотек закреплены в проекте.
Из корня репозитория:

```bash
export JAVA_HOME=/path/to/jdk-17
export ANDROID_HOME=/path/to/Android/Sdk
./gradlew testDebugUnitTest assembleDebug lintDebug --no-daemon
```

Debug APK создаётся как `app/build/outputs/apk/debug/app-debug.apk`; его applicationId —
`dev.siyovush.parentcast.tv.debug`. Минимальный SDK — 33, целевой стенд M0 — H728 с Android 14.

## Запуск на однозначно опознанной H728

Не используйте эти команды для случайного телефона или неопознанного ADB-устройства.
Установка не меняет Launcher, HOME, Device Owner или системные настройки:

```bash
adb -s <SERIAL_H728> install -r app/build/outputs/apk/debug/app-debug.apk
adb -s <SERIAL_H728> shell am start -n dev.siyovush.parentcast.tv.debug/dev.siyovush.parentcast.tv.ui.MainActivity
```

Очередь изначально пуста. На экране просмотра удержание MENU/DPAD Center (или Ctrl+Alt+P на клавиатуре) открывает
только форму PIN. После правильного PIN доступен экран родителя. Добавьте обычную, короткую или Shorts YouTube-ссылку, затем нажмите
«Играть». Back из debug-экрана возвращает плеер. Во время видео собственные кнопки и YouTube UI
не отображаются.

## Веб-пульт M1

1. При первом запуске задайте PIN из 6–12 цифр на родительском debug-экране.
2. Для смены PIN введите действующий и новый PIN. Очистка данных приложения не требуется.
3. На телефоне или Ubuntu откройте `http://parentcast-tv.local:8765/` или отсканируйте QR
   в родительском меню ТВ. Если имя недоступно в вашей сети, переключите QR на адрес IPv4
   кнопкой под ним. Введите действующий родительский PIN и нажмите «Войти».
   Дополнительный код и открытие окна доступа на ТВ не нужны. После 5 неверных попыток
   вход с адреса клиента ограничивается на 10 минут; уже авторизованные браузеры продолжают работать.
4. Каждый браузер сохраняет отдельный случайный токен, поэтому при повторном открытии PIN не нужен.
   Токены можно отозвать на ТВ или в панели; они не помещаются в URL. После отзыва нужен новый вход
   по PIN. Существующие токены сохраняются при обновлении приложения.
5. Добавление ссылок не запускает просмотр. Для немедленного запуска есть отдельная команда
   «Включить сейчас». Статусы и ошибки приходят от Media3, а не означают успех по HTTP 200.
6. Закрытие браузера не останавливает приставку. После перезапуска приложения сохраняются
   очередь, позиция и намерение PLAY/PAUSE/STOP.

M1 использует HTTP только внутри доверенной домашней сети. Трафик не шифруется; HTTPS,
управление через интернет и публичная панель не реализованы. Тестовая YouTube-сессия M1 не
выдаётся за production-авторизацию.

## Плейлисты и сохранённые подборки M2

В панели вставьте ссылку в отдельный раздел импорта плейлиста и получите предпросмотр.
Отметьте ролики и нажмите «Добавить выбранные». Ни получение списка, ни сохранение подборки
не запускают плеер. Для завершённых VOD с неизвестной доступностью это явно написано:
список YouTube не доказывает будущего воспроизведения. Ошибки страниц помечены PARTIAL;
выбрать можно только явно полученные допустимые элементы. Неподтверждённая публичность
блокирует применение, плейлисты более 500 элементов отклоняются с объяснением.

«Сохранить выбранные как подборку» создаёт приватный фиксированный список videoId на приставке.
Подборку можно посмотреть, добавить повторно или удалить. Изменение исходного YouTube-плейлиста
её не обновляет. Добавление использует queueVersion и один атомарный batch с receipt;
повтор команды после потери ответа не дублирует элементы (окно идемпотентности 24 часа).
Предпросмотр отменяется и истекает через 15 минут; это временные данные, а не подписка.

Поддержаны публичные статические PL/OLAK5uy плейлисты. Mix, uploads/feed, private/unlisted,
эфиры и премьеры не поддерживаются. Получение списка анонимное и не меняет тестовые cookies,
которые существующий плеер продолжает использовать. Результаты: `docs/reports/M2.md`.

## HOME и локальный родительский вход M3

Удерживайте MENU или DPAD Center (3 секунды, также поддержан стандартный long-press),
чтобы открыть форму родительского PIN M1. Неверные попытки ограничены: 5 за 10 минут,
счётчик сохраняется после перезапуска. Настройки закрываются при уходе из приложения,
возврате к просмотру и через 2 минуты бездействия. PIN не добавляется в URL или логи.

Сначала проверьте доступность сохранённого Launcher в настройках. Нажмите «Выбрать ParentCast
как HOME» и завершите штатный Android-выбор. Затем включите детский просмотр. Автозапуск
обеспечивает сама система для выбранного HOME, без фонового boot receiver. Автопродолжение PLAY
по умолчанию выключено: при новом запуске сохранённый PLAY становится PAUSE с той же позицией;
PAUSE/STOP не запускаются самопроизвольно. Явная команда PLAY веб-пульта работает отдельно.

Для выхода откройте PIN-форму, войдите и нажмите «Вернуть штатный Launcher и отключить HOME».
Просмотр остановится, детский режим выключится, собственный HOME alias отключится.
Android предложит выбрать штатный HOME: отметьте сохранённый Launcher и нажмите «Всегда»; факт проверяется resolver,
а не только появлением Launcher на экране. Запасной путь владельца по уже проверенному ADB:
`python3 tools/m3_restore_home.py --serial <H728_SERIAL> --home <SAVED_HOME_COMPONENT>`.

**HOME + PIN не блокируют системные выходы.** В обычном APK настоящий Lock Task запускается только
при официальном разрешении DPC, screen pinning не используется как замена. На стенде Device Owner
отсутствует; его назначение не выполняется. Фактические ограничения и NOT_RUN reboot при
неподтверждённом возврате ADB перечислены в `docs/reports/M3.md`. M4 не реализуется.

По отдельному дополнению M3 подготовлен вариант `assemblePrivileged`: тот же debug package и signer,
но отдельная private Activity `lockTaskMode="always"`. В Android 14 этот путь требует установки,
распознанной как privileged, и фактического `LOCK_TASK_MODE_LOCKED`. Кандидат на H728 не устанавливался,
первый пробный сеанс не включается автоматически после boot. Для исследования не нужен приватный
platform-ключ. Проверенные свойства прошивки, ограничения данных и условный план установки/отката:
[`docs/M3-privileged-plan.md`](docs/M3-privileged-plan.md). Обычный `assembleDebug` не содержит ALWAYS Activity.

## Главные границы

Только родительский выбор. Никаких рекомендаций, встроенной страницы YouTube,
переходов во внешнее приложение или Google Login через WebView. Тестовые cookies допускаются
только в debug при ручном включении владельцем; агент не читает их содержимое. Это не production-
авторизация. Рекламу и другое содержимое внутри роликов родители проверяют самостоятельно.
Неофициальный способ получения потоков принят владельцем с риском периодических поломок.

M0–M1 — прототип плеера и родительского пульта, **не защищённое детское устройство**.
До приёмки режима HOME/Lock Task нельзя оставлять ребёнку приставку как готовое ограниченное устройство.

## Домашний доступ и очистка

После запуска ParentCast на ТВ пульт работает в фоновой службе с постоянным уведомлением.
Можно уйти в штатный Launcher или закрыть экран приложения: очередь и подготовка остаются
доступны. При уходе с экрана ТВ текущий просмотр ставится на паузу; для нового PLAY откройте
ParentCast на телевизоре. Принудительная остановка Android выключает и службу — снова
откройте приложение. Автозапуск после reboot отдельно не добавлялся.

Для семьи: подключите приставку и телефон к одной обычной домашней сети, откройте QR
на ТВ, один раз введите PIN и сохраните страницу в избранное или на главный экран браузера.
Подсеть может быть любой: адреса/QR обновляются, локальное имя объявляется самим приложением.
Поддержка `.local` зависит от клиента и роутера; QR с текущим IP остаётся запасным способом.
На Ubuntu с прокси добавьте имя/адрес приставки в исключения; гостевая Wi-Fi с изоляцией
не подходит. Открывать порт роутера в интернет не нужно.

В панели:

- «Очистить всю очередь» — после подтверждения STOP удаляет текущий элемент, ожидающие
  и историю очереди. Скачанные файлы и сохранённые подборки остаются.
- «Удалить только ожидающие» — прежнее действие M1, сохраняет текущий и историю.
- «Удалить файл» / «Удалить все скачанные файлы» — после подтверждения освобождают медиа;
  очередь, подборки, PIN, cookies и браузерные доступы остаются. Подготовка приостанавливается;
  текущий удаляемый ролик останавливается. Для повторного скачивания нажмите «Подготовить очередь».
- «Все готовые файлы на приставке» показывает также файлы вне оставшейся очереди.

Хранилище показывает фактически занятое/свободное место и допустимый остаток с резервом.
Прогресс учитывает видео и звук вместе; 100% появляется только после проверки полного файла.
Если точный размер ещё неизвестен, показывается текущий этап и индикатор без выдуманного процента.
Результаты проверки: [docs/reports/Home-admin-usability.md](docs/reports/Home-admin-usability.md).

## Автовосстановление, свои видео и USB

Новая отдельная ветка после PR #9: `tasks/Resumable-local-videos.md`. Приложение предназначено
для детей: только явный родительский выбор, готовность после проверки полного файла, никакого
неожиданного PLAY и никаких новых роликов без родительского добавления.

**YouTube:** при временной сетевой ошибке сохраняется часть файла, выполняется новый resolve
для свежего URL, повтор с задержкой5–300с (Retry-After до10мин). Возврат проверенной Android-сети
ускоряет повтор. Сначала восстанавливается ближайший незавершённый элемент программы;
поздняя большая загрузка не оттесняет его. Пауза сохраняет partial, удаление медиа удаляет и
partial/sidecar. Докачка разрешена только с проверенной идентичностью формата, сильным HTTP
validator,206/Content-Range и общим размером. При200/неподтверждённом продолжении — безопасный
restart. Недоступное видео, авторизация и ошибка места требуют понятного действия родителя;
они не превращаются в частые бесконечные запросы. Готовые файлы остаются локальными.

**Свои видео:** в Chrome откройте «Свои видео / USB» → «С телефона / компьютера…», выберите
до20файлов и нажмите «Скопировать на приставку». Процент передачи не означает готовность:
после него проверяются контейнер, длительность, наличие декодеров и SHA. Поддержаны MP4/MKV/
WebM/3GP с кодеками данной приставки, без DRM; автоматического перекодирования нет. Ошибка
оставляет файл вне списка готовых. Импорт не меняет очередь. В «Уже на приставке» отметьте
видео → «Добавить выбранные в программу»; затем «Смотреть» у нужной строки программы.

**USB на приставке:** подключите флешку, откройте родительский PIN-вход на ТВ и нажмите
«Выбрать папку USB / локальных видео». В штатном Android-окне разрешите чтение нужной папки.
Нельзя выбирать корень внутреннего хранилища; используйте конкретную папку. Затем в веб-пульте
«Флешка, вставленная в приставку» → «Открыть USB-папку», отметьте файлы и скопируйте.
Доступ только к выбранному дереву и только чтение; исходные файлы не удаляются. Флешку можно
вынуть после READY. Выбор папки можно отозвать в родительском меню; скопированные видео
останутся. Извлечение USB во время копирования даёт ошибку, а не ложную готовность.

Свои видео хранятся в private media и не вытесняются очисткой YouTube-кэша. Общий бюджет
всех медиа/partial —10GiB, резерв1GiB. Удаление своего файла — отдельная подтверждаемая команда.
Локальные IDs имеют отдельный namespace и source-признак, поэтому отсутствие файла не
перенаправляет ребёнка на YouTube. Очередь v1 читается и сохраняется как v2 с этим признаком;
APK versionCode7. Перед аппаратным обновлением сохраняется приватный контрольный снимок.

**Порядок:** «Моя программа» → «Изменить порядок». Перемещайте ожидающие ролики стрелками,
на нужную позицию или мышью; есть сортировка по названию и готовности. До «Сохранить порядок»
это только черновик. Текущий ролик/история не двигаются; конфликт с другим браузером требует
повторной проверки списка. Названия YouTube появляются по мере получения метаданных;
неизвестное название отображается ID. «Смотреть» явно выбирает существующую строку без
добавления дубликата. Импорт, сортировка и готовность файла сами не запускают просмотр.

## Повторы в очереди

Один videoId добавляется в текущую очередь один раз, включая текущий ролик и историю.
Повтор ссылки, плейлиста или сохранённой подборки пропускает уже добавленные видео; новые
добавляются по порядку. Пульт показывает число новых и пропущенных роликов, а полностью
добавленный выбор — «Уже в очереди». Для повторного просмотра нажмите «Смотреть» у существующей
строки; «Включить сейчас» тоже использует её. После удаления записи/очистки можно добавить
ролик снова. Подробности: tasks/Queue-deduplication.md.

## VK: видео и плейлисты

В пульте можно добавлять ссылки вида `https://vkvideo.ru/video-227392256_456239129`.
Нужен доступный без входа завершённый ролик с H.264/AAC до1080p. VK всегда сначала
полностью скачивается в приватное хранилище и проверяется; нажмите «Подготовить очередь»,
дождитесь «Готово» и явно нажмите «Смотреть». Файлы доступны офлайн. YouTube cookies в VK
не передаются. Закрытые видео, авторизация VK, эфиры, DRM и перекодирование не поддерживаются.

Для списка откройте «Плейлисты», вставьте `https://vkvideo.ru/playlist/-227392256_1/`,
нажмите «Получить предпросмотр», отметьте нужные ролики и подтвердите добавление либо
сохранение подборки. `/season_0` и видео со ссылкой `?pl=-227392256_1` в этом разделе
обозначают тот же список; в обычном добавлении видео ссылка с `?pl=` добавляет только ролик.
Другие сезоны и канальные ленты не поддерживаются. Лимит —500; неполный ответ —PARTIAL.
«Доступность не проверена» не гарантирует скачивание: окончательная проверка при подготовке.
Названия/длительности и полный порядок получаются из страниц VK; нет автоматической
подписки на изменения. Подборки содержат фиксированные ID, повторы общей очереди пропускаются.

## Плейлисты в «Моей программе»

Импорт теперь создаёт отдельную карточку плейлиста с названием, источником, порядком и
счётчиком готовых роликов. В предпросмотре можно задать понятное название перед добавлением.
Сохранённая подборка добавляется такой же карточкой. Это фиксированный список; новые видео
автора сами не появляются. Общие ролики двух плейлистов используют одну запись и один файл.

У карточки есть «Подготовить плейлист», «Смотреть плейлист сначала», стрелки порядка списков
и «Изменить порядок видео». Подготовка не останавливает текущий просмотр. Для просмотра без
ожиданий дождитесь готовности всех роликов. Первый ролик должен быть готов перед запуском;
в конце выбранного списка —STOP, другой плейлист сам не включается. Ролик можно выбрать
отдельно внутри этого списка. В локальном режиме незагруженный показывает состояние вместо
кнопки просмотра; потоковый YouTube-режим остаётся отдельной прежней возможностью.

Внутри плейлиста можно переставлять все ролики, включая текущий и историю: до «Сохранить
порядок» это черновик. Сам плеер/позиция при сохранении не меняются; следующий ролик будет
выбран по новому порядку. Удаление плейлиста из программы сохраняет скачанные файлы,
сохранённые подборки и общие видео других списков. Если удаляется выбранный список,
воспроизведение останавливается. Одиночные и старые видео без данных об источнике показаны
отдельно по YouTube/VK/своим файлам. Старый именованный список можно восстановить кнопкой
«Добавить как плейлист» у сохранённой подборки без дублей видео.

Названия из новых предпросмотров сохраняются вместе с программой/подборкой. Если название
старого видео неизвестно, показана подпись «Название ещё не получено», ID — вторично;
метаданные появятся при подготовке. Очередьv3 читаетv1/v2; откат на старый APK без отдельной
миграции queuev3 не поддерживается. Не очищайте данные приложения ради отката.
