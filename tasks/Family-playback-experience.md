# Удобство программы и просмотр со скачиванием — 2026-11-06

Статус: реализация завершена; приёмка VK/web/TV PASS, ранний просмотр YouTube
не подтверждён (PREVIEW_TIMEOUT), физическая microSD/reboot NOT_RUN. Владелец явно поручил реализовать весь согласованный список
возможностей после семейного интерфейса. Ветка `codex/family-playback-experience`
от `694fe1e` (Draft PR #18), без Merge. Это отдельное расширение HOME BETA.

## Согласованный объём

1. Исправить редактор отдельных видео (не затрагивает группы) и сортировку готовности
   при отключённой карте. Общий редактор порядка видео/плейлистов: мышь/касание,
   прокрутка при перетаскивании, начало/конец/позиция, закреплённые Save/Cancel,
   предварительное «Далее», атомарные версии и повтор команд.
2. Массовые выделение/перемещение/скачивание, copy/move между плейлистами, rename,
   избранные, собственная обложка или кадр, безопасная отмена структурного действия.
3. Просмотр со скачиванием через общий устойчивый кэш. Приоритет текущего видео/seek,
   retry и обновление временной ссылки без смешивания разных представлений;
   полная подготовка остаётся отдельным режимом. Никакой ложной READY для partial.
4. Единая карточка ссылки: обложка, название, длительность, доступные480/720/1080p
   и известный размер; явные смотреть+сохранять / скачать позже / добавить в плейлист.
   Вставка ссылки и предпросмотр не запускают воспроизведение.
5. Следующим, закончить после ролика, позиция каждого видео, история статусов,
   именованные закладки, готовая длительность программы и двойная шкала.
6. Полировка mobile/desktop, контекстные меню, анимации с reduced-motion.
   Опциональный TV-экран: крупные карточки только разрешённых родителями групп,
   управление DPAD. Это выбор программы, не новая kiosk-защита.

## Границы и сохранность

Владелец одобрил общий кэш/изменение пути воспроизведения, включая VK; прежний prepared-only
для VK заменяется только явно выбранным новым режимом. Сохранять существующие готовые
файлы, очередь, группы, подборки, позиции и PIN/cookies/tokens. Не сбрасывать доступ,
не включать автоматическое удаление, не скачивать новые авторские видео без выбора.
Не обновлять Media3/yt-dlp без необходимости. Использовать существующие PIN/API/HTTP,
SSRF/Host/Origin/CSRF ограничения и один Android-модуль.

Обычные код/тесты/debug update без очистки/commit/push/Draft PR разрешены. Работа через
домашний ПК сохраняется. Без Merge, Release, reboot, format, system/vendor, privileged,
platform signing, нового DO, Happ или других приложений. M4 как отдельный этап не начинать;
одноразовое «остановить после ролика» разрешено этим запросом, расписания не добавлять.
Во время разработки просмотр не прерывать; аппаратную приёмку проводить с сохранением
контекста. Реальную microSD нельзя считать проверенной до подключения носителя.

## Приёмка

- Unit/API: миграция, все операции порядка и undo, конфликт/повтор, защита текущего,
  progress/history/bookmarks/stop-after/next; cache-range/retry/cancel/seek/качество/квота.
- Chrome: настоящий pointer/touch editor,320/390/desktop, длинные списки, dirty/conflict,
  XSS, новые кнопки только с явным действием, link errors, отсутствие скрытого PLAY.
- Debug APK, unit, lint, JS, release compile; signer/appId/version совместимы с H728.
- Подтверждённая H728: данные до/после, реальные YouTube/VK ранний старт+сохранение,
  повтор из локального файла, STOP/seek/NEXT, детский DPAD/возврат PIN, реальный веб-пульт.
  Синтетические проверки не выдавать за аппаратные; недоступные сценарии NOT_RUN.
- Отчёт `docs/reports/Family-playback-experience.md`; каждый пункт списка имеет итоговый
  статус, конкретное ограничение или доказательство. APK SHA, commit и Draft PR.
