# Подготовленная программа — отдельное задание после HOME BETA

Владелец 2026-11-03 явно одобрил план полной предварительной загрузки выбранной
очереди и загрузки следующих видео во время локального просмотра. Это разрешение
расширяет прежний запрет скачиваемой видеотеки только на этот режим. M4/privileged
не входят. Ветка codex/prepared-programme от HEAD PR #7 (2f0e90f), отдельный Draft PR,
без Merge. Незавершённые изменения smoother-buffering сохранены git stash, не включены.

## Результат и границы

- Родитель явно включает режим в существующей защищённой панели.
- Фиксированная текущая очередь, без каналов/рекомендаций/динамической подписки.
- Последовательная фоновая подготовка публичных завершённых YouTube VOD,
  приватные файлы, video/audio H.264/AAC, без platform signing/обновления yt-dlp/Media3.
- READY только после полного EOF/Content-Length и проверки контейнера; контрольная
  сумма/размер защищают от локального повреждения. Частичные файлы не воспроизводятся.
- В режиме подготовки PLAY ждёт локального READY; STOP/NEXT отменяют ожидание;
  запоздавшая подготовка не запускает STOP. Готовый текущий играет, следующие готовятся.
- Ограничения2GiB/резерв1GiB, ошибки/прогресс/пауза/retry, очистка файлов вне оставшейся
  очереди. Порядок/queueVersion/PIN/cookies/tokens/подборки сохраняются.
- После смерти процесса готовые файлы восстанавливаются, незавершённые скачиваются
  заново при продолжении подготовки (не обещаем byte-range resume). Reboot не проверять.
- Это ограниченный локальный режим, не гарантирует отсутствие декодерных сбоев.
  Первый запуск и неподготовленный следующий требуют ожидания; веб-пульт сообщает честно.

## Проверки

Тесты: полная/обрезанная загрузка, лимит/резерв, отмена, corruption/recovery,
порядок, local-only source и STOP/NEXT stale result, API auth/CSRF/version/idempotency,
XSS-safe frontend. Gradle unit/lint/debug/release-code и JS.
H728/Ubuntu: подготовить реальные короткие YouTube VOD, запустить локальный файл,
следующий/STOP, проверить данные и штатный Launcher. Реальное отключение сети и reboot
не подменять синтетическими тестами; не менять Happ/VPN/систему.


В ходе аппаратной проверки выяснилось: ParentCast и его данные ранее удалены владельцем.
Владелец подтвердил чистую установку на этой H728. Создан новый тестовый PIN штатным UI,
секрет в .dev/prepared/test-pin (600, ignored). Для YouTube потребовались cookies: владелец
предоставил локальный путь, файл скопирован непрозрачно и сессия включена штатным UI.
Не заявлять сохранность удалённых до задания данных; сохранять новую установку/сессию.
