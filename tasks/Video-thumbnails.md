# Превью видео и продолжение просмотра

Статус: DONE. Ветка `codex/video-thumbnails`, база PR #14.

Владелец запросил работу через домашний ПК: превью YouTube/VK и кадры своих видео.
Первоначально просмотр нельзя было прерывать; затем владелец явно разрешил остановить
просмотр для обновления и добавил продолжение с сохранённого места после паузы/прерывания/ребута.

- Миниатюры в текущем ролике, программе/редакторе, импорте, загрузках и локальной библиотеке.
- YouTube: публичная обложка; VK: известная обложка либо кадр готового файла, для ещё
  неготового ролика анонимное получение только метаданных pinned yt-dlp.
- Свои видео: масштабированный кадр из готового приватного файла, без запуска player.
- Авторизация тем же отдельным токеном; токены и внешние URL не попадают в img.src.
- Ленивые запросы, один worker, максимум16 заданий, JPEG до96КиБ, кэш32МиБ.
- Кэш производный/удаляемый, вне очереди и пользовательских настроек.
- Явная кнопка «Продолжить с …» сохраняет контекст и позицию текущего ролика;
  «Смотреть плейлист сначала» остаётся отдельной явной командой.
- Существующая безопасная startup policy сохраняется: выключенный автостарт или сохранённая
  PAUSE не запускают ролик сами. После ручного открытия приложения можно продолжить.
- Без reboot, HOME/system/Happ/privileged изменений и сброса данных; без Merge.

Проверки: JVM (async/cache/auth/limits/URL/migration/position), JS, lint, debug APK,
release compilation; H728 update и короткая проверка изображений/продолжения.
Реальный reboot и неподключённый USB: NOT_RUN.

Результат: обычный debugv12 установлен на подтверждённую H728. 266 JVM PASS;
lint0errors/46warnings, release compile, пять JS syntax checks и шесть JS contract scripts PASS.
Chrome headless на домашнем Ubuntu: реальные картинки видимы, JS exceptions0;
десктоп1280px и viewport390px. Продолжение158726→164075ms, затем принудительный
перезапуск только приложения восстановил PAUSE164075ms/тот же плейлист.
Данные99роликов/2плейлистов, PIN/токены/подборки/настройки сохранены. Итог — PAUSE.
Отчёт: `docs/reports/Video-thumbnails.md`. Реальный reboot не выполнялся.
