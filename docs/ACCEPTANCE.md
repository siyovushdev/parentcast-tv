системной установкой отдельно согласовать образ/раздел/версию/signer/UID, приватный backup и откат;
до этого аппаратные сценарии privileged NOT_RUN. `docs/M3-privileged-plan.md`.

## Защита очереди от дублей

- Повторы по videoId исключены для ссылок/playlist/collection/local/native; история и текущий
  учитываются, новые элементы сохраняют первый порядок. PLAY_NOW использует существующую строку.
- Другой ключ/браузер/источник не добавляет копию; idempotency+счётчики переживают restart.
- No-op не меняет queueVersion/позицию/intent; stale409 не меняет очередь, реальное добавление атомарно.
- UI busy/«Уже в очереди»/точные added+skipped; данные/защита сохраняются.
Результаты и границы аппаратной проверки: reports/Queue-deduplication.md.
