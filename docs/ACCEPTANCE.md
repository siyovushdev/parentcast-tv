# Приёмка

Статусы: **PASS**, **FAIL**, **NOT_RUN**. Для каждого аппаратного пункта записать
устройство/ОС, commit, настройки потока, действия, наблюдение и очищенное свидетельство.
Этот файл — план тестов, не результат выполненных проверок.

Для M0-05 нужен хотя бы один настоящий естественный конец короткого тестового видео;
перемотка к финалу может ускорять остальные проверки, но не заменяет все события окончания.
Минимальный сеанс на стенде — 20 минут суммарно, не считая одной лишь загрузки APK.
Unit-тесты покрывают порядок/stop/restart/stale response/error и нормализацию ссылок.
Сетевые живые тесты отделены от детерминированных unit-тестов.
Если H728 недоступна, код и сборку можно закончить, но аппаратную приёмку пометить NOT_RUN.

Reboot выполнять только после подтверждения безопасного возврата Launcher и ADB. При отсутствии
последнего — NOT_RUN по указанию владельца. Перезапуск приложения и unit-тест не подменяют reboot.
Результаты: `docs/reports/M3.md`. HOME/immersive без управляемого Lock Task не являются kiosk-защитой.

Дополнение privileged: отдельная private ALWAYS-root, фактический LOCKED без DO, PIN → finish root →
NONE → обычный HOME/Launcher, отсутствие повторного входа после отказа/смерти процесса. Перед
системной установкой отдельно согласовать образ/раздел/версию/signer/UID, приватный backup и откат;
до этого аппаратные сценарии privileged NOT_RUN. `docs/M3-privileged-plan.md`.

## M4

Управление с другой сети; отсутствие публично открытой панели; недоступность домашнего
SSH-узла (если выбран); отключение приставки; честные статусы и отсутствие позднего сюрприз-запуска.
Непрерывное воспроизведение выбранной очереди минимум два часа и возврат после обрыва сети.

## Подготовленная программа (отдельно разрешена 2026-11-03)

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| PP-01 | Явное включение и повтор команды | Подготовка очереди без PLAY, прежняя версия/порядок очереди; fingerprint/idempotency |
| PP-02 | Полный файл / обрыв / отмена / checksum | READY только после EOF, размера и контейнера; partial не воспроизводится, corruption требует retry |
| PP-03 | Полный локальный просмотр | Media3 открывает только private file, движется позиция, естественный конец и следующий |
| PP-04 | Фоновая подготовка | Текущий local играет, следующий готовится, STOP/NEXT отвечают во время ожидания |
| PP-05 | Лимит и очистка | 2GiB и резерв1GiB; просмотренные удаляются вручную/под давлением лимита, оставшаяся очередь защищена |
| PP-06 | Перезапуск процесса | READY восстанавливаются без сетевого resolve; incomplete готовятся заново при продолжении |
| PP-07 | PIN/Host/Origin/CSRF/XSS | Новые команды/статусы защищены M1; строки — textContent, экспорт media URLs отсутствует |
| PP-08 | Данные и система | Не изменены HOME/Happ/DO/системные разделы; cookies/PIN/tokens сохраняются |

Физическое отключение сети, reboot и длительный многочасовой сеанс отдельно от локальной
проверки file datasource; не заявлять их PASS без фактического исполнения.
