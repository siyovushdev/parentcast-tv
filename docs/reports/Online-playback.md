# Прямой онлайн-просмотр — 2026-11-06

IN SCOPE. Отдельный режим «Смотреть онлайн» реализован поверх существующих
Media3/PlaybackCoordinator/LAN API. Обычная debug-установка без очистки на
подтверждённой H728 Android14, serial …84201a; работа через домашний Ubuntu.
Статус: реализовано. VK480p — PASS в коротком испытании; время старта/seek —

## Изменение поведения

В предпросмотре ссылки доступны «Смотреть онлайн», «Смотреть и сохранять»,
«Скачать для просмотра позже» и прежнее добавление в программу без запуска.
Онлайн не требует выбора/доступности microSD и не резервирует место для файла.
В программе сохраняются явно выбранный родителем ролик, качество и режим;
подписанные CDN URL остаются только в RAM. Новый metadata-журнал атомарный,
без cookies/токенов/видеобайтов. Пауза/позиция/перемотка и отдельный STOP сохранены.
Режим запоминается: «Смотреть и сохранять» переключает обратно на путь подготовки,
используя уже готовый локальный файл, если он есть; «Скачать позже» не переключает
способ уже идущего просмотра. Готовые файлы/частичный cache сами не удаляются.

Новый DataSource отдаёт сетевые байты в Media3 по мере чтения непрерывного HTTP
ответа, без ожидания полной сборки512KiB блока, SimpleCache, media writes и quota
scans. Seek использует Range. Проверяются статус/диапазон/известный полный размер;
неподдерживаемый Range и смена представления дают явную ошибку. При403/410 URL
обновляется один раз на open; временные сетевые ошибки повторяются существующей
политикой загрузки. STOP/смена ролика отменяют активные HTTP calls.

HTTPS/CDN allowlist и каждый redirect проверяются, DNS запрещает private/loopback/
link-local адреса. YouTube cookies добавляются только к разрешённому YouTube CDN
через прежнюю сессию; VK не получает ни их, ни Cookie/Authorization из extractor.
PIN/токены/Host/Origin/CSRF, queueVersion, идемпотентность и защита от дублей сохранены.
Конкурентный STOP во время получения параметров предотвращает отложенный PLAY.

Фоновые подготовительные загрузки временно уступают приоритет онлайн-просмотру.
Это не меняет сохранённые enabled/paused/план; STOP и PAUSE возвращают прежний фон.
Пульт показывает «Онлайн · без сохранения на карту» и шкалу реального RAM-буфера,
а не процент сохранения. Целевой размер буфера Media348MiB, интервалы30–90s,
стартовый порог3s, после опустошения5s. Это целевые параметры, не гарантия времени.
По умолчанию выбирается самое высокое реально доступное качество не выше480p;
720/1080p доступны вручную. Автоматического переключения bitrate в этом progressive
режиме нет. Версии Media3/yt-dlp не менялись, DASH/HLS не добавлялись.
