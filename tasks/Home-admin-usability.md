# Домашний пульт и управление хранилищем — 2026-11-03

Владелец запросил удобный LAN-доступ для семьи, очистку/удаление, использование до10ГиБ
и видимый прогресс загрузок в процентах. Ветка codex/home-admin-usability от Draft PR #8
(ab645ca), отдельный Draft PR, без Merge. PIN/cookies/tokens/подборки сохранять.

## Объём

- QR на ТВ с актуальным LAN URL (без PIN/token в коде), инструкция первого входа и сохранения
  страницы, несколько независимых браузерных токенов. Сервер не обходит прокси клиента:
  домашняя сеть должна идти напрямую, отдельная гостевая Wi-Fi может быть изолирована.
- Изменение владельца HTTP/Media3 из Activity в одну фоновую службу предложено владельцу
  отдельно; владелец явно согласовал перенос API и плеера в службу. Без BOOT/reboot/DO/privileged.
- Очистить всю очередь с явным STOP и queueVersion, удалить отдельный скачанный файл,
  удалить все скачанные файлы. Подтверждение в интерфейсе; PIN/cookies/авторизация не сбрасываются.
- До10GiB медиа, резерв1GiB, фактические used/free. Нехватка места обрабатывается штатно;
  устройство искусственно не заполнять ради аппаратного теста.
- Процент считается по точному общему размеру video+audio. Unknown total — indeterminate;
 99% до проверки/READY,100% только READY. Этапы metadata/video/audio/verification.
