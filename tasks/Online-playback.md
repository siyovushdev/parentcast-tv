# Прямой онлайн-просмотр — 2026-11-06

IN SCOPE: владелец одобрил отдельное «Смотреть онлайн» без обязательной записи на
microSD. Приоритет — быстрый запуск и устойчивый детский просмотр; не обещать
нулевую буферизацию без реального испытания. Сохранить stream+save и полную подготовку.

Один существующий Media3/координатор/API. Прямой поток с ограниченным RAM-буфером,
без cache/media writes, квоты и обязательного доступного накопителя. Адреса источника
только в RAM; сохраняются лишь ID/качество/выбранный режим. Проверять CDN/redirect/DNS,
YouTube cookies только своему источнику. Метаданные вне main thread, STOP отменяет
сеть; фоновые загрузки временно уступают онлайн-просмотру, настройки родителя сохраняются.

Существующие версии/идемпотентность/защита API, позиции/перемотка/порядок и данные
сохранить. Ясный режим и буфер в веб-пульте, отдельные действия онлайн/сохранение/позже.
Качество только реально доступное; адаптивный DASH/HLS не обещается для progressive MP4.
Обычный debug update без очистки; H728 проверить по serial, сохранить контекст.
Без Merge/reboot/системных изменений/Happ/platform signing/удаления готовых файлов.

Проверки: progressive HTTP/seek/partial-read, отмена/expiry/redirect/SSRF/cookies,
отсутствие media writes, независимость от microSD, повтор команды и конкурентный STOP,
веб mobile/desktop; unit/lint/debug/release/JS. Реальные VK и YouTube отдельными PASS/FAIL/NOT_RUN,
время запуска и повторная буферизация, сохранность данных. После приёмки Draft PR к PR #19.
