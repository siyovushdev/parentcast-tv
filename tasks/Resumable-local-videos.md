# Восстановление загрузок, свои видео и USB — 2026-11-03

Владелец отдельно разрешил автоматическое восстановление сетевых обрывов/докачку,
импорт локальных видео из браузера и USB приставки, удобную сортировку и родительский UI.
Ветка codex/resume-local-videos от 9f9c7de (Draft PR #9), отдельный Draft PR, без Merge.

Детский экран остаётся просмотром только выбранной родителем программы. Надёжность,
сохранность данных, ясные статусы/ошибки и отсутствие неожиданного PLAY — основные критерии.
Не считать неполный файл готовым; не подменять реальную аппаратную проверку заглушкой.

- HTTP Range/If-Range: сохранять partial и подтверждённую идентичность представления;
  append только при корректном206/Content-Range/validator/общем размере. Если докачка не
  подтверждена — безопасный restart; обновлять истёкший URL через штатный yt-dlp без хранения URL.
- Автоматические сетевые retry с задержками, отмена/пауза отзывчивы, причина/следующая попытка
  видны родителю. Авторизация/неподдерживаемое видео/место не должны вызывать busy loop.
- Свои видео копируются в private media, проверяются до READY, сохраняются без зависимости
  от браузера/USB/YouTube и используют общий лимит10GiB/reserve1GiB. Никакого автоматического
  сканирования/добавления посторонних роликов. Файлы USB только из явно разрешённой папки SAF.
- Сортировка ожидающих элементов (перенос к позиции/порядок целиком, сортировка по названию)
  атомарна с queueVersion/idempotency; текущий ролик и история не меняются, PLAY не вызывается.
- Новые upload/USB/local API используют PIN-токены, Host/Origin/CSRF, лимиты, случайные
  имена файлов; никаких произвольных путей/URL. Названия — textContent.

Проверки: реальные Range/обрыв/обновление metadata и строгие206/200/416/validator тесты;
restart/пауза/retry/STOP; upload точной длины/лимит/отмена/повтор/подмена/невалидное медиа;
миграция очереди/local-only playback/сортировка/stale/replay; USB извлечение/права; JS UI.
APK/unit/lint/release Kotlin, H728 и обычный браузер. Существующие PIN/cookies/tokens/очередь/
подборки сохранить. Happ/систему/HOME/DO/privileged/reboot не менять. USB требует физической
флешки; запрос владельцу отправлен, остальные задачи не блокируются.
