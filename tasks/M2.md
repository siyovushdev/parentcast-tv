# M2 — YouTube-плейлисты и сохранённые подборки

База: `m1/lan-parent-control`, `a0744f74f71936983ab322c6c74168f5d3429e42`.
Ветка: `m2/playlist-import`; Draft PR в M1. PR #1–#4 не сливать.

Статус: реализация и аппаратный импорт/сохранение/воспроизведение завершены.
Факты, APK и границы проверок: `docs/reports/M2.md`.

## Реализация

- Приставка получает метаданные публичного статического плейлиста через существующий yt-dlp,
  без загрузки видео. Все страницы, исходный порядок, количество, лимит 500 с явным превышением.
- Веб-предпросмотр: названия, известные метаданные, недоступные и неизвестные элементы;
  PARTIAL с причиной при неполных данных. Отмена фоновой задачи без блокировки STOP/NEXT/Media3.
- Checkbox, выбрать все/снять, отменить, явное «Добавить выбранные». До применения очередь не меняется.
- Добавление выбранных атомарно, идемпотентно, с queueVersion; не запускает и не прерывает плеер.
- Именованные сохранённые подборки — фиксированный упорядоченный снимок videoId в приватном
  хранилище H728; просмотр, повторное добавление, удаление; без автоматического обновления.
- Сохранить PIN, токены, Host/Origin/CSRF, строгий whitelist входных ссылок, безопасный DOM.

## Проверки

Unit/integration: многостраничность, пагинационные ошибки, скрытые/удалённые и неизвестные,
неверные ссылки, 500/501, отмена, порядок, повтор, конкурентная версия, неизменность снимка.
Реальная H728 + Ubuntu-браузер: получение YouTube-плейлиста, предпросмотр, выбор, применение,
сохранение подборки и воспроизведение выбранного видео. APK update без очистки данных, tests/lint.
Каждому аппаратному пункту PASS/FAIL/NOT_RUN и очищенное свидетельство; synthetic не заменяет YouTube.

private/Mix/live, подписок, рекомендаций, скачивания библиотеки, смены yt-dlp/Media3 без доказательств.
